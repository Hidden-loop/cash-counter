# Cash Counter PWA

A professional Progressive Web App for counting money denominations and tracking totals. Supports **multiple profiles** for different contexts (work, personal, events). Works on **desktop, tablet, and mobile** (Android & iOS).

Perfect for:
- Bank tellers counting cash
- Business owners tracking daily income
- Event organizers counting ticket sales
- Retail staff reconciliation

## 🚀 Quick Start

### Desktop / Web
1. Open in your browser (Chrome, Firefox, Safari, Edge)
2. Click the install icon in the address bar (varies by browser)
3. Or visit the app for full offline support

### Android Phone / Tablet
1. Open in Chrome browser
2. Tap the **⋮** (three dots) menu
3. Tap **"Install app"** or **"Add to Home screen"**
4. The app appears on your home screen as a standalone app

### iPhone / iPad
1. Open in Safari browser
2. Tap the **Share** button
3. Tap **"Add to Home Screen"**
4. Name it and tap **Add**
5. The app appears on your home screen

## ✨ Features

### Core Features
- **Quantity Counter**: Enter how many of each denomination you have
- **Name Entry**: Add names directly to the total display (e.g., "Morning Opening")
- **Real-time Calculation**: Instant total based on quantities
- **Negative Support**: Enter -5 to -1 to correct/remove miscounted notes (shows in RED)
- **Multi-Profile System**: Keep separate logs for Work, Personal, and custom profiles
- **Denomination Support**: 500, 200, 100, 50, 20, 10 (notes), 5, 2, 1 (coins)
- **Saved Counts**: Every count is logged with timestamp, name, category, and notes

### 🎨 Themes (Updated!)
- **Slate** (purple) - Modern default
- **Navy** (blue) - Professional 
- **Forest** (green) - Natural
- **Minimal** (gray) - Clean
- Switch themes anytime using dropdown in header

### ✏️ Edit Mode with Entry Preservation
- **Click any saved entry** to open edit mode
- **Original entry is preserved** - never overwritten!
- **Creates a new entry** from your edits with full history
- **Split-view display**:
  - Left: Original quantities 
  - Right: Updated quantities with +/− buttons
- **Visual differences**: Green (added) or red (removed)
- Perfect for adding cash found later without losing the original count

### 🎯 Multi-Select Operations
- **Click "Select" button** in history to enable multi-select
- **Checkboxes appear** next to each entry
- **Select multiple entries** to combine or subtract
- **Two operations**:
  - **➕ Add**: Combine all selected entries into your counter
  - **➖ Subtract**: Remove selected entries from counter
- Use for: Consolidating counts, removing duplicates, calculating net changes

### 📝 Names, Notes & Categories (✨ New!)
- **Name field**: Right at the top where total is shown (not in modal)
  - Type as you enter quantities

- **Add notes**: Extra context (e.g., "Found loose change", "End of shift")
- **Categorize transactions**:

  - **Add custom categories** as needed

- **Filter by category**: Quickly find counts from specific operations

### 🎯 Category Management

- **Create custom categories**: Click "➕ Category" to add your own
- **Filter history**: Click category buttons to see only those entries

## 📋 How to Use

### Step 1: Select Profile & Theme
- Choose from Work, Personal, or create new profile
- Select theme (Slate, Navy, Forest, Minimal) from dropdown
- Each profile keeps separate counts

### Step 2: Add Entry Name & Enter Quantities
- **Name field** at top (right where total shows)
- Type the entry name (e.g., "Morning Opening", "Customer Deposit")
- Enter quantities for each denomination
- **Negative support**: Use − button to go down to -5 (for removing/correcting notes)
  - Example: If you miscounted 5 notes, enter -5 to subtract them
  - Shows in RED for easy visibility
- Use + button to add more
- See running total update in real-time (red if negative)

### Step 3: Select Category & Add Notes
- **Category dropdown**: Choose transaction type (Opening Balance, Sales, Refund, Deposit, Withdrawal, Other, or custom)
- **Notes field**: Optional context (e.g., "Found loose change", "End of shift count")
- Both fields saved with entry

### Step 4: Save Count
- Click **"💾 Save Count"** button
- Entry saves with name, category, notes, and all denomination details
- Timestamp automatically recorded

### Step 5: Edit Existing Entries
- **Click any entry** in History to open edit mode
- **Split view opens**:
  - Left: Original quantities you counted
  - Right: Updated quantities with + and − buttons
  - Supports -5 to +∞ for correcting mistakes
- **Shows differences**: Green (added) or red (removed)
- Update name, category, notes as needed
- Make changes and click **"Save as New"**
- **Original entry is preserved** - creates new entry from edits
- Perfect for correcting mistakes or adding cash found later

### Step 6: Multi-Select Operations (Combine Counts)
- Click **"Select"** button in History section
- **Checkboxes appear** next to entries
- Check the entries you want to combine
- Choose **➕ Add** or **➖ Subtract**:
  - **Add**: Combines all selected entries into your counter
  - **Subtract**: Removes selected entries from counter
- Useful for: Consolidating morning/afternoon/evening counts, removing duplicates

### Step 7: Filter by Category
- **Category buttons** appear above history
- Click **"All"** to see all entries
- Click **category name** to filter entries
- Perfect for finding specific transaction types

### Step 8: Create Custom Categories
- Click **"➕ Category"** button below history
- Enter custom category name (e.g., "Daily Close", "Audit", "Recount")
- New category appears as filter button
- Assign to future entries

### Step 9: Export Records
- Click **📊 CSV** for Excel/spreadsheet import (includes names, categories, notes)
- Click **📄 JSON** for backup/detailed records
- Exports include negative values so you can see corrections
- Share files via email or storage

- Data stored locally on device - check browser storage

### Offline not working
- First visit must be online to cache files
- Service Worker needs to load once
- Check browser settings allow offline

### Can't export
- Check if browser allows downloads
- Verify notification permissions
- Try different export format

## ✏️ Edit Mode - Add More Cash to Existing Counts

One of the best features: **edit any saved count to add more notes later!**

**Example:**
1. You count cash at 3 PM: 10×500 + 16×200 + 37×50 = ₹11,430
2. More cash comes in at 4 PM
3. Click the 3 PM entry → Edit mode opens with split view
4. Right side shows the original quantities
5. Use + button to add new notes (e.g., add 5 more 500-notes)
6. See the difference highlighted: +5 notes, +₹2,500
7. Click "Save Changes" → Entry updates to ₹13,930

**Benefits:**
- Don't create duplicate entries
- Track all additions to same batch
- See exactly what was added/removed
- Keep clean, organized history
